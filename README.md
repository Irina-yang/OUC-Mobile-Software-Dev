### [实验2：名片小程序](./实验2_名片小程序)
* **状态**：✅ 已完成
## ✨ 功能与视觉亮点
本项目是中国海洋大学《移动软件开发》课程的“实验2”产出。这是一个基于微信小程序原生开发的高颜值、清新风格的个人电子名片。
* **🍃 清新极简 UI**：采用浅蓝色（`#eaf4fc`）全局底色，摒弃过度华丽的装饰。采用白色悬浮卡片式设计，视觉体验干净利落。
* **📱 刘海屏自适应**：精准计算顶部 `margin` 安全距离，完美避开手机物理刘海与系统状态栏对头图文字的遮挡。
* **🗂️ 模块化数据渲染**：
  * **基础信息区**：展示姓名、专业及联系方式，支持动态标签（Tags）渲染。
  * **个人履历区**：采用类似“百度百科”风格的时间线排版，清晰展示社团与社会实践、专业技能与项目研发、个人特长等详尽履历。
* **🌊 丝滑滚动体验**：底层采用 `<scroll-view>` 结合 `enable-flex="true"` 技术，完美解决小程序 Skyline 引擎下的卡片挤压变形问题，支持长履历顺畅滑动翻页。
* **🔗 一键社交分享**：集成微信原生分享接口，支持将名片卡片直接发送给好友或分享至朋友圈。
* **实验报告**：完整的设计方案、核心源码解析及开发过程中“图片路径对齐”的排查心得，已记录在对应的实验报告文档中。
  
## 🛠️ 技术栈与核心实现

* **WXML**：页面结构搭建，使用 `wx:for` 实现数据列表动态渲染，运用 `<scroll-view>` 构建基础滚动容器。
* **WXSS**：深入运用 Flexbox 弹性盒布局，配合响应式视口单位（`vw`, `vh`）与绝对居中对齐（`margin: auto`）解决渲染引擎偏移 Bug。
* **JavaScript**：页面生命周期管理，基于 `Page.data` 的数据双向绑定机制。

## ✨ 功能与视觉亮点
本项目是中国海洋大学《移动软件开发》课程的“实验3”产出[cite: 1, 3]。这是一个模仿网易新闻与高校官方新闻网、基于微信小程序原生开发的高颜值、清新风格的高校新闻客户端。

* **🎨 清新极简 UI**：采用浅蓝色全局主色调[cite: 1] 与沉浸式顶部导航栏，搭配卡片式列表设计，视觉体验干净利落。
* **🖼️ 动态轮播与专题分类**：
  * **幻灯片组件**：集成 `<swiper>` 实现多图自动循环播放与圆点指示器[cite: 3]。
  * **专题导航**：顶部支持多分类标签切换（海大要闻、学术前沿等）[cite: 1]。
* **🔍 智能搜索与快捷交互**：
  * **搜索栏**：内置实时搜索及本地历史搜索记录管理功能[cite: 1]。
  * **回到顶部**：右下角悬浮快捷按钮，优化长页面浏览体验[cite: 1]。
* **📑 图文混排与拓展下载**：
  * **正文排版**：严格规范新闻详情页图文混排，正文支持段首空两格，图片完美自适应[cite: 1, 3]。
  * **离线下载**：创新支持将新闻文字导出为 Word 文档到本地[cite: 1]。
* **⭐ 本地收藏与右滑管理**：
  * **缓存机制**：基于 `wx.setStorageSync` 实现新闻的高效本地添加与取消收藏[cite: 3]。
  * **便捷手势**：支持列表项右滑快捷移除收藏，告别繁琐的详情页取消操作[cite: 1]。
* **👤 个人中心与资料修改**：
  * **授权登录**：支持微信底部授权弹窗，安全获取并渲染用户头像与昵称[cite: 1, 3]。
  * **个性化编辑**：支持点击头像或昵称旁的修改符号自定义修改个人资料[cite: 1]。
  * **动态同步**：实时读取本地缓存渲染个性化收藏列表，点击即可无缝跳转阅读[cite: 3]。
* **实验报告**：完整的设计方案、核心源码解析及开发过程中的排查心得，已记录在对应的实验报告文档中。

## 🛠️ 技术栈与核心实现

* **WXML**：页面结构搭建，运用 `wx:for` 实现新闻列表与收藏夹的动态数据渲染，配合 `<swiper>` 构建轮播容器[cite: 3]。
* **WXSS**：深入运用 Flexbox 弹性盒布局，配合尺寸单位（`rpx`）与视图容器样式重构，确保多端显示适配。

### [实验4：推箱子游戏](./实验4_推箱子游戏)

- **状态**: ✅ 已完成

### ✨ 功能与视觉亮点

本项目是中国海洋大学《移动软件开发》课程的“实验4”产出。这是一个基于微信小程序原生开发的、采用粉色治愈系UI的高级推箱子益智小游戏。

- 🎨 **视觉与渲染引擎**:
  - **高清 Canvas 2D**: 摒弃旧版接口，采用原生 Canvas 2D 并获取设备 DPR 动态缩放画布，彻底解决高分屏画质模糊与锯齿问题。
  - **图片内存池**: 预加载所有游戏素材至内存池，确保滑动与撤销时画面渲染零延迟、零闪烁。
- 🎮 **多模态双轨操作**:
  - **全屏手势滑动**: 绑定触摸事件，支持手指在屏幕任意位置滑动控制主角移动，告别呆板的虚拟按键。
  - **精准坐标点击**: 换算 `e.detail` 坐标，支持点击主角相邻方格进行精准寻路控制。
- ⏪ **状态历史栈与容错**:
  - **历史回溯**: 基于深拷贝维护 `history` 状态数组，实现“撤销一步”功能，完美解决将箱子推入死角的挫败感。
  - **物理震动反馈**: 深度调用原生 Haptics，提供行走与推箱子的轻震动（`vibrateShort`）以及通关时的长震动反馈（`vibrateLong`）。
- 👤 **原生授权与本地排行**:
  - **新版微信授权**: 接入最新的 `chooseAvatar` 与 `nickname` 填写组件，完美规避废弃 API 限制，安全获取真实用户资料。
  - **闭环排行榜**: 基于 `wx.setStorageSync` 构建本地成绩排行，按最少步数智能排序展示，并对前三名赋予高亮皇冠样式。
- ⚠️ **未完全完成功能说明**:
  - **寻路解答降级**: 考虑到移动端 JS 主线程性能，放弃执行完整的 A* 寻路回放，采用“撤销”功能兼顾容错与设备运行性能。
  - **单机模式降级**: 因未部署独立后端且未开启云开发，全局排行榜与辅助道具功能暂被搁置，采用本地缓存完成闭环演示。
- **实验报告**: 完整的需求分析、UI设计规范（含色彩卡）与核心引擎重构逻辑，已记录在对应的实验报告文档中。

### 🛠️ 技术栈与核心实现

- **前端开发**: 微信小程序原生开发
- **核心组件**: `<canvas type="2d">`、`<button open-type="chooseAvatar">`
- **状态解耦**: 基于二维数组实现地图地形（静态）与动态物体（箱子/主角）的逻辑分离与同步渲染

### [实验5：鸿蒙开发入门及计算器开发](./实验5_鸿蒙开发入门及计算器开发)

- **状态：** ✅ 已完成

### ✨ 功能与视觉亮点

本项目是中国海洋大学移动开发相关课程的优质产出。这是一个基于 HarmonyOS 与 ArkTS 原生开发，媲美主流系统级原生体验（如 iOS 计算器）的高颜值、多功能智能计算器客户端。

* 📱 **响应式多形态 UI 与安全区域适配**：
  * **横竖屏自适应**：基于 `mediaquery` 实现布局重构，竖屏保留大尺寸基础键盘，横屏自动丝滑展开为 `5x4` 科学计算矩阵。
  * **高质感视觉**：全屏叠加微弱背景滤镜与毛玻璃（`BlurStyle`）特效，利用精准 Padding 完美避开前置摄像头与安全区域，告别 UI 截断。
* 🧮 **苹果级智能解析引擎**：
  * **算式步骤可视化**：摒弃易误触的“即时求值”，支持长达 35 位的完整算式步骤实时预览（`Text` + `Span` 差异化渲染）。
  * **自动纠错与补全**：底层封装 `evaluateSmart` 递归引擎，实时自动补全缺失的灰色右括号。
  * **精准科学计算**：内置极小值浮点误差过滤机制，完美支持超大数科学计数法（`e`）、阶乘、三角函数（支持 RAD/DEG 状态实时切换指示）等复杂运算。
* 💱 **多维换算与极客模式**：
  * **极客模式 (Geek Mode)**：针对网安/计科背景设计，实时监听十进制结果，利用位运算（`>>> 0`）无缝同步展示无符号十六进制（Hex）与二进制（Bin）数值。
  * **动态汇率换算**：顶部下拉菜单支持一键切换货币（USD/EUR）与数据单位（MB/GB）换算，结果区动态追加带有目标单位的换算隔离行。
* 📚 **持久化历史记录栈**：
  * **双向绑定缓存**：基于 ArkTS 的 `PersistentStorage` 实现历史记录的本地磁盘级持久化，杀后台或重启数据不丢失。
  * **丝滑交互**：新记录产生时，利用 `Scroller` 控制器自动平滑滚动至列表底部，并在顶部导航栏提供一键 `CLEAR` 清空功能。
  * **实验报告**：完整的设计方案、核心正则解析逻辑及开发过程中的排查心得，已记录在对应的实验报告文档中。

### 🛠️ 技术栈与核心实现

* **ArkTS**: 深入运用页面生命周期与严格类型检查，借助 `@State`、`@Watch` 实现核心数据驱动的跨组件状态自动重绘。
* **ArkUI**: 混合运用 `Stack`、`Column`、`Row` 与 `Grid` 弹性盒布局，配合三元运算符动态控制属性，确保多端显示与横竖屏完美适配。
* **正则与算法**: 面对 ArkTS 严禁 `eval()` 的限制，自主编写并优化带有防死循环（AppFreeze）安全锁的正则表达式解析器，实现对内层括号和数学函数的递归剥离计算。
* **本地存储**: 使用 `PersistentStorage` 与 `@StorageLink` 装饰器，实现历史数据栈的高效本地读取与写入机制。

### ✨ 功能与视觉亮点

本项目是中国海洋大学《移动软件开发》课程的“实验6”产出。这是一个基于微信小程序原生云开发构建的高颜值、强互动的“小红书风格”图片分享社区。

- 📱 **小红书风 UI 架构**：采用扁平化三大主干道（首页/发布/我的）结合顶部导航流。动态卡片采用左图右文极简排布，文案区引入智能文本截断与“展开全文”机制，视觉体验干净利落。
- 🖼️ **九宫格与沉浸式大图**：视觉区完美还原标准 3x3 九宫格矩阵渲染（超限自动渲染 `+N` 蒙层）。支持单图点击唤起带灰色半透明背景的沉浸式居中大图预览。
- 💬 **反套路互动体验**：摒弃传统底栏，重构为侧重内容消费的定制化组件：
  - **👎 负反馈静默过滤**：点击后平滑移除当前动态，无社交压力。
  - **💬 沉浸式评论**：采用底部升起的半屏弹窗（Bottom Sheet），保持背景界面的连续性。
  - **👍 震动点赞**：融入微动效及触觉震动反馈。
- ☁️ **多账号全网数据互通**：彻底攻克微信云开发免费版的“权限物理隔离”壁垒。利用云函数（Cloud Function）超级管理员权限与 `getTempFileURL` 动态链接转换，完美实现多账号图文可见、点赞评论实时互通。
- 🔥 **双重复合智能排序**：实现“热度优先（点赞数），时间次之”的复合排序算法。运用严谨的跨平台时间戳解析逻辑（兼容 iOS/Android），实现热帖自动置顶与新帖倒序呈现。
- 📝 **实验报告**：完整的系统架构设计、云开发多账户权限踩坑实录及底层接口重构心得，已详细记录在对应的实验报告文档中。

### 🛠️ 技术栈与核心实现

- **WXML & WXSS**：深入运用 Flexbox 弹性布局构建复杂动态流，结合 CSS 多行文本截断与视口单位（vw/vh）打造响应式排版。
- **JavaScript (前端)**：深度运用原生 JS 数组高阶函数进行复杂数据清洗与状态绑定，编写工业级的时间解析工具函数拦截 iOS 端 `NaN` 报错。
- **微信云开发 (CloudBase)**：
  - **云函数 (Node.js)**：编写并部署 `getPosts` 等云函数，充当后端数据代理，强行穿透 `_openid` 的读写权限隔离。
  - **云数据库 (NoSQL)**：设计高扩展性的 JSON 文档结构，支持图片数组、点赞名单、评论嵌套对象的高效读写与关联更新。
  - **云存储 (Storage)**：统筹管理图片资源，利用云端 API 批量将私有 `cloud://` 协议实时签发为公网安全的 HTTPS 临时访问凭证。
