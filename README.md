### [实验1：第一个微信小程序](./实验1_第一个小程序)
* **状态**：✅ 已完成
* **目录结构说明**：
  为了落实“学习使用快速启动模板”和“学习不使用模板”的双重学习目标，本次实验代码分为两部分提交：
  1. `Code_使用模板`：包含了利用官方默认模板快速生成的完整项目脚手架，用于了解官方推荐的文件组织规范和基础工具类 (`utils`) 的使用。
  2. `Code_手动创建`：包含了在“不使用模板”的纯净环境下，从零手写的 `Hello World` 交互程序，用于最直观地验证 `this.setData()` 数据绑定机制。
* **实验报告**：详细的错误排查和总结均已附在同级目录下的实验报告文档中。

### [实验2：名片小程序](./实验2_名片小程序)
* **状态**：✅ 已完成
* **项目内容说明**：基于微信小程序原生开发的一款个人电子名片。整体 UI 遵循清新简洁的设计风格，融合了以下核心开发技术：
  * **数据与视图分离**：将姓名、学校、专业、联系方式及个人标签等数据统一抽离至 `index.js` 的 `data` 对象中，通过 `{{}}` 语法和 `wx:for` 列表渲染进行动态绑定。
  * **响应式与层叠布局**：采用 WXSS 的 Flex 弹性盒模型控制元素对齐，并通过负外边距（`margin-top`）与阴影效果实现信息卡片悬浮于 16:9 头图之上的立体视觉。
  * **全局色调定制**：将页面底层背景色设定为柔和清爽的浅蓝色（`#eaf4fc`）。
* **实验报告**：完整的设计方案、核心源码解析及开发过程中“图片路径对齐”的排查心得，已记录在对应的实验报告文档中。
