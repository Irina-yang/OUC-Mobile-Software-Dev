### [实验2：名片小程序](./实验2_名片小程序)
* **状态**：✅ 已完成
## ✨ 功能与视觉亮点
本项目是中国海洋大学《移动软件开发》课程的“实验2”产出。这是一个基于微信小程序原生开发的高颜值、清新风格的个人电子名片。
* **🍃 清新极简 UI**：采用浅蓝色（`#eaf4fc`）全局底色，摒弃过度华丽的装饰。采用白色悬浮卡片式设计，视觉体验干净利落。
* **📱 刘海屏自适应**：精准计算顶部 `margin` 安全距离，完美避开手机物理刘海与系统状态栏对头图文字的遮挡。
* **🗂️ 模块化数据渲染**：
  * **基础信息区**：展示姓名、专业及联系方式，支持动态标签（Tags）渲染。
  * **个人履历区**：采用类似“百度百科”风格的时间线排版，清晰展示社团与社会实践、专业技能与项目研发、个人特长等详尽履历。
* **🌊 丝滑滚动体验**：底层采用 `<scroll-view>` 结合 `enable-flex="true"` 技术，完美解决小程序 Skyline 引擎下的卡片挤压变形问题，支持长履历顺畅滑动翻页。
* **🔗 一键社交分享**：集成微信原生分享接口，支持将名片卡片直接发送给好友或分享至朋友圈。
* **实验报告**：完整的设计方案、核心源码解析及开发过程中“图片路径对齐”的排查心得，已记录在对应的实验报告文档中。
  
## 🛠️ 技术栈与核心实现

* **WXML**：页面结构搭建，使用 `wx:for` 实现数据列表动态渲染，运用 `<scroll-view>` 构建基础滚动容器。
* **WXSS**：深入运用 Flexbox 弹性盒布局，配合响应式视口单位（`vw`, `vh`）与绝对居中对齐（`margin: auto`）解决渲染引擎偏移 Bug。
* **JavaScript**：页面生命周期管理，基于 `Page.data` 的数据双向绑定机制。

# 实验3：高校新闻网

* **状态：** ✅ 已完成

## ✨ 功能与视觉亮点

本项目是中国海洋大学《移动软件开发》课程的“实验3”产出[cite: 1, 3]。这是一个模仿网易新闻与高校官方新闻网、基于微信小程序原生开发的高颜值、清新风格的高校新闻客户端。

* **🎨 清新极简 UI**：采用浅蓝色全局主色调[cite: 1] 与沉浸式顶部导航栏，搭配卡片式列表设计，视觉体验干净利落。
* **🖼️ 动态轮播与专题分类**：
  * **幻灯片组件**：集成 `<swiper>` 实现多图自动循环播放与圆点指示器[cite: 3]。
  * **专题导航**：顶部支持多分类标签切换（海大要闻、学术前沿等）[cite: 1]。
* **🔍 智能搜索与快捷交互**：
  * **搜索栏**：内置实时搜索及本地历史搜索记录管理功能[cite: 1]。
  * **回到顶部**：右下角悬浮快捷按钮，优化长页面浏览体验[cite: 1]。
* **📑 图文混排与拓展下载**：
  * **正文排版**：严格规范新闻详情页图文混排，正文支持段首空两格，图片完美自适应[cite: 1, 3]。
  * **离线下载**：创新支持将新闻文字导出为 Word 文档到本地[cite: 1]。
* **⭐ 本地收藏与右滑管理**：
  * **缓存机制**：基于 `wx.setStorageSync` 实现新闻的高效本地添加与取消收藏[cite: 3]。
  * **便捷手势**：支持列表项右滑快捷移除收藏，告别繁琐的详情页取消操作[cite: 1]。
* **👤 个人中心与资料修改**：
  * **授权登录**：支持微信底部授权弹窗，安全获取并渲染用户头像与昵称[cite: 1, 3]。
  * **个性化编辑**：支持点击头像或昵称旁的修改符号自定义修改个人资料[cite: 1]。
  * **动态同步**：实时读取本地缓存渲染个性化收藏列表，点击即可无缝跳转阅读[cite: 3]。
* **实验报告**：完整的设计方案、核心源码解析及开发过程中的排查心得，已记录在对应的实验报告文档中。

## 🛠️ 技术栈与核心实现

* **WXML**：页面结构搭建，运用 `wx:for` 实现新闻列表与收藏夹的动态数据渲染，配合 `<swiper>` 构建轮播容器[cite: 3]。
* **WXSS**：深入运用 Flexbox 弹性盒布局，配合尺寸单位（`rpx`）与视图容器样式重构，确保多端显示适配。
* **JavaScript**：页面生命周期管理（如 `onLoad`、`onShow`）[cite: 3]，封装公共逻辑函数（`common.js`）[cite: 3]，基于本地缓存（`StorageSync`）实现离线收藏夹与搜索记录的持久化存取。
